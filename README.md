# Nitin Keshava Hegde — Portfolio

Personal portfolio site built with React and Vite, showcasing my projects, education, and certifications.

## Sections

- **About** — intro and quick links
- **Projects** — featured work with filterable categories, tech stack tags, and links to source/live demos
- **Education** — academic timeline
- **Documents** — resume and certifications, viewable in-browser
- **Contact** — email and social links

## Tech Stack

- React 19
- Vite
- Framer Motion
- lucide-react / react-icons

## Getting Started

```bash
npm install
npm run dev
```

Other scripts:

```bash
npm run build    # production build
npm run preview  # preview the production build
npm run lint     # run ESLint
```
